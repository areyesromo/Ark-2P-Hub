# Fonts for the themes

Bundled so the hub works offline (a Pi, the desktop app). Picked in Settings → Theme; the default
theme uses the system font. All three are under the SIL Open Font License 1.1 (the LICENSE files
here), from the Fontsource packages on npm, Latin subset.

- Big Shoulders Display (800, 900): the Neon theme's names, scores and game titles.
- Atkinson Hyperlegible (400, 700): body text in the Neon and Cozy themes, made to be easy to read.
- Fraunces (700, 900): the Cozy theme's game box titles.
