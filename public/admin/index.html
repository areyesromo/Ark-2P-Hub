ARK 2P HUB · Settings

Settings opens on this hub's home network only (and from Player 1's phone: ⋯ → ⚙ Settings).

Theme

The colours and fonts of the TV and the phones. It changes on every screen straight away.

Layout

How the lobby is arranged on the TV and the phones. Any theme goes with any layout.

Join address

The address phones open when they scan the QR code on the TV. Use this machine's LAN IP and port, e.g. http://192.168.1.50:3000.

Online play

The TV's 🌍 Invite someone online button opens a temporary internet address (a free Cloudflare quick tunnel) so a friend somewhere else can join from their phone, with a remote screen to watch the TV. Only the game pages go out: this Settings page stays at home.

Already run a Cloudflare tunnel (or another https address) to this hub? Put its address here and the button uses it instead of a quick tunnel.
