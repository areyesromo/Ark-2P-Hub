# Kart Race art

Placeholder art, cropped from the character and kart sheets; replace any file with a clean
version of the same name and size and it shows up as is.

- `portraits/<racer id>.webp`: square, round face (the screens add the gold rim), 160×160.
- `karts/<racer id>.webp`: the kart seen from above, **nose pointing up**, transparent
  background, wheels included, 256 px tall. Drawn 1.25 field units long on the track.
  Racers with no kart picture yet (listed in `SPRITES` in `../racers.js`) are drawn as shapes;
  add the file and the id to `SPRITES`.

Racer ids: rex, roxy, zip, zara, swift, sky, boulder, bella, dash, daisy, rascal, ruby.

Notes on the placeholders: Roxy, Zara, Sky, Bella and Ruby's karts are recolours of their
partner's kart (Zara's and Sky's still say ZIP and SWIFT on the nose); Dash and Daisy have no
kart picture yet.
