# Game ideas

Ideas for new Party Minigames, Micro Mayhem minis and full games, waiting their turn. This is the working
backlog, not the bucket list: pick from here when choosing what to build next. Each gets a short
design when its turn comes.

**Pick from this list.** Don't brainstorm new games while it still has ideas; only once it's empty do
we discuss more. Take an idea off the list when it ships.

**Look** says who builds what (see `docs/3D-HANDOFF.md`):

- **2D**: done here, start to finish.
- **3D base**: done here with simple shapes (boxes, spheres, cylinders); playable and shippable as is.
- **3D art**: the base is done here, then the local session adds models, scenery and animation from a
  brief in `docs/3D-HANDOFF.md`.

# Casino, card and board games

Full games (their own lobby entry), not minis. Only games with clear rules a computer can play well:
no games judged on taste or humour (Cards Against Humanity, Dixit, Apples to Apples), and no word
association (Codenames). Games for 3 or more get a 2-player version if one exists.

**Cards are real decks**: shuffle once, deal from the top, reshuffle only when it runs out (as Crazy
Eights does). Never make up a card at random. Famous trademarked names get our own name.

## Notes

- Every idea needs a computer player (see `server/games/minis/bots.js`) and a controller mapping.
- Timing ones judge the press on the server with `lagFor` (see `runner.js`), like Musical Chairs.
- Before building, check the name isn't a famous game's and that it's not the same as an existing
  mini (`server/games/minis/`).
